# 11 — Milestones

## M0 — Foundation

**Status:** 🟢 Active / documentation foundation substantially complete.

Deliverables: repository, North Star, constitution, skill set, roadmap, architecture, research plan, experiment framework, decision log, budget policy, agent registry.

## M1 — First Working Agent

User task → planner → coding agent → GitHub artifact.

## M2 — Persistent State

SQLite orchestration state + Git project state.

## M3 — Context Handoff

Reliable Agent A → Agent B continuation.

## M4 — Multi-Agent

Planner → Developer → Reviewer → Tester.

## M5 — Dynamic Selection

Meta-Agent selects an agent based on task/resource state.

## M6 — Recovery

Rate limits, failures, timeouts, invalid output, and test failures trigger recovery/replanning.

## M7 — Cost Engine

Budget-aware routing and cost telemetry.

## M8 — Verification

Automated build/test/review gates.

## M9 — Benchmark

Controlled comparison against baselines.

## M10 — CAOS Alpha

End-to-end autonomous development prototype under explicit budget and human-approval controls.

## Exit-Criteria Rule

A milestone is not complete because code exists. It is complete when its acceptance criteria are demonstrated and documented.
