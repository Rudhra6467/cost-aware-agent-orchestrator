# 13 — Future Scope

These capabilities are deliberately outside the initial MVP unless experiments demonstrate that they are necessary.

- Larger provider/model discovery and resource monitoring
- Automated free-tier/rate-limit intelligence
- More sophisticated DAG scheduling
- Parallel agent execution
- Vector/semantic project memory
- Dockerized isolated code execution
- Security scanning and policy enforcement
- Autonomous GitHub pull requests
- Deployment automation
- Long-running project maintenance
- Multi-language software generation
- Human approval policies by risk level
- Marketplace/provider abstraction
- Multi-project orchestration
- Enterprise cost governance

Future scope must not displace the core research objective before the benchmarkable CAOS Alpha exists.
