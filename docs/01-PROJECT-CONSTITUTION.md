# 01 — Project Constitution

## Non-Negotiable Principles

1. **Functionality before appearance** — working software is the first success criterion.
2. **Cost is first-class** — every execution is evaluated economically, including nominally free resources.
3. **Verification over assertion** — generated code must be tested; an agent saying “it works” is not evidence.
4. **Persistent continuity** — an agent failure must not erase project knowledge or progress.
5. **Provider independence** — no single model/provider should become architecturally indispensable.
6. **Meta-Agent over model loyalty** — the orchestrator selects agents based on task requirements and current conditions.
7. **Measure before optimizing** — performance, quality, reliability, tokens, latency, and cost are recorded before optimization claims are made.
8. **Free-first** — paid APIs are used only when a measurable bottleneck justifies them.
9. **Controlled autonomy** — human approval remains in the loop for consequential actions until reliability is demonstrated.
10. **Reproducibility** — experiments, decisions, configurations, and results are versioned.

## Engineering Doctrine

**Plan → Select → Execute → Persist → Verify → Recover/Replan → Measure.**

## Research Doctrine

The project must distinguish between:

- capability claims,
- measured performance,
- economic cost,
- reliability,
- and hypotheses about future performance.

No provider should be considered “best” without task-specific evidence.
