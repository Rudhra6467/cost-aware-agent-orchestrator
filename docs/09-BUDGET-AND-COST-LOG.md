# 09 — Budget and Cost Log

## Budget Policy

CAOS is a budget-constrained project. The default development target is **$0 recurring spend** until a paid resource is demonstrated to solve a measurable bottleneck.

## Execution Modes

- **ZERO:** maximize free/open resources; no paid API spend.
- **MICRO:** allow a tightly capped experimental spend.
- **LOW:** optimize cost/quality within a small project budget.
- **FLEXIBLE:** research mode for controlled paid-model comparisons.

Exact monetary limits will be set before experiments that incur cost.

## Required Telemetry

Every execution should eventually record:

- provider/model
- task
- input tokens
- output tokens
- API calls
- estimated cost
- execution duration
- retries
- failures
- final status
- quality/test result

## Cost Optimization Rule

Never choose a paid agent simply because it is perceived to be better. A paid choice should be justified by expected capability, reliability, time, or quality improvement relative to incremental cost.
