# 10 — Agent Registry

This registry will become the source of truth for agent-selection experiments. Initial entries should be based on tested configurations rather than marketing claims.

## Agent Record

Each agent/model should eventually include:

- Agent ID
- Provider
- Model
- Role capabilities
- Coding score
- Architecture score
- Research score
- Reasoning score
- Context capacity
- Input cost
- Output cost
- Free-tier conditions
- Rate limits
- Availability
- Reliability/failure rate
- Average latency
- Last tested date
- Benchmark notes

## Initial Status

No provider/model has been formally benchmarked yet.

The first registry should remain intentionally small. We will add providers as the system requires them rather than attempting to catalogue the entire AI ecosystem.

## Selection Principle

Agent choice should be task-specific. A single global ranking is not the objective.
