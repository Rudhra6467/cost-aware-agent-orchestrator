# 02 — Skill Set

This project uses a progressive learning model. The goal is not to become an expert programmer before building CAOS; learning is attached to each implementation milestone.

## Level 0 — Existing Foundation

- Basic understanding of consumer AI tools
- AI/LLM concepts
- Prompting and agent concepts
- Product thinking

## Level 1 — Required Technical Foundation

- GitHub: repositories, commits, branches, pull requests
- JSON and structured data
- HTTP/API fundamentals
- Authentication/API keys
- Basic command line usage

## Level 2 — Visual Orchestration

- n8n workflows
- Nodes and data mapping
- Expressions
- Conditions and branching
- Loops
- HTTP Request nodes
- Webhooks
- Error handling
- Execution history

## Level 3 — Practical Python

- Variables, functions, lists, dictionaries
- Conditions and loops
- JSON
- HTTP requests
- Exceptions and logging
- SQLite
- Basic typing/dataclasses
- FastAPI and pytest later

## Level 4 — Agent Engineering

- System prompts
- Structured outputs
- Tool calling
- Context windows
- Token accounting
- Agent roles
- Task decomposition
- Retry/fallback strategies
- Evaluation

## Level 5 — Orchestration Engineering

- DAGs
- Task dependencies
- Routing
- State machines
- Agent scoring
- Resource selection
- Failure recovery
- Verification
- Consensus

## Level 6 — Research

- Experimental design
- Baselines/control groups
- Benchmark construction
- Metrics
- Reproducibility
- Cost/quality trade-off analysis
- Context retention measurement

## Learning Rule

Learn the minimum concept required for the current milestone, immediately apply it, test it, document it, then continue. Avoid broad courses that are disconnected from the current build.
