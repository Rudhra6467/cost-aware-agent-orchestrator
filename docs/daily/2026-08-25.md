## Important architectural decisions made today

1. GitHub/Git owns project artifacts; SQLite owns orchestration telemetry.
2. Provider SDKs stay behind an adapter interface.
3. Deterministic routing is the baseline before any LLM-based routing is introduced.
4. Single-agent execution is validated before multi-agent autonomy.
5. Free-first remains a project constraint and research variable.
